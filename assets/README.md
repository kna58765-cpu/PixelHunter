# PixelHunter yellow character assets

Place the files from the supplied `PixelHunter_yellow_assets.zip` into this folder (`assets/`) without renaming them.

Required files:
- yellow_1.webp, yellow_2.webp, yellow_3.webp (normal yellow enemies)
- yellow_1_green.webp, yellow_2_green.webp, yellow_3_green.webp (green boss variants)
- yellow_1_purple.webp, yellow_2_purple.webp, yellow_3_purple.webp (purple boss variants)
- yellow_attack.mp3 (audio extracted from the supplied video)

The game code already loads these exact paths. Keep the original aspect ratios; the game scales the sprites proportionally.
